

Con el algoritmo de Hamming, es posible **detectar y corregir** errores en las palabras gracias a **los bits de paridad**.

Dependiendo de cuántos bits de paridad metamos las palabras de un código, cambiará la $d_{min}$ entre palabras válidas dentro del código.  

| Código                            | Bits totales | $d_{min}$ | Qué consigue                              |
| --------------------------------- | ------------ | --------- | ----------------------------------------- |
| Solo el mensaje (M3 M5 M6 M7)     | 4            | 1         | Nada: todas las combinaciones son válidas |
| Mensaje + 1 bit de paridad        | 5            | 2         | Detecta 1 error                           |
| Hamming (P1, P2, P4 + mensaje)    | 7            | 3         | Corrige 1 error                           |
| Hamming + 1 bit de paridad global | 8            | 4         | Corrige 1 error y detecta 2               |
En esta tabla se demuestra que 
- Para **detectar $s$ errores** necesitas $d_{min} ≥ s + 1$
- Para **corregir t errores** necesitas $d_{min} ≥ 2t + 1$
- Para corregir t y detectar s a la vez (con s > t) necesitas $d_{min} ≥ t + s + 1$. 
*Con $t = 1$ y $s = 2$ sale $d_{min}=4$.*
