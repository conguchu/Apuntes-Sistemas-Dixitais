
**128 caracteres** codificados en **7 bits**, aunque se añade un 0 a la posición más significativa para que sean 8.

Codifica:
- Letras A-z *(minus. y mayus.)*
- Caracteres especiales (<, >, =, ...)
- Números 0 - 9
- Códigos de control.

Existe también el **ASCII extendido** creado por IBM incorporando el 8º bit para añadir **128 nuevos caracteres**. Permite codificar caracteres alfabéticos no ingleses, símbolos no ingleses, letras griegas, símbolos matemáticos, caracteres no gráficos, caracteres gráficos de barras y caracteres sombreados, ...
