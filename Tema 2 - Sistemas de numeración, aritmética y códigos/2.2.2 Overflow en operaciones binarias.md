Se produce cuando **el resultado de una operación no cabe en los bits disponibles**. *Por ejemplo*: sumando $2+2$ con solamente dos bits disponibles ocurre esto:

|             | 1   | 0   |
| ----------- | --- | --- |
| +           | 1   | 0   |
| Resultado-> | 0   | 0   |
El resultado sería $100_2$, que es $4$, el cual ocupa 3 bits. **Se pierde información al no tener suficientes bits disponibles**.
