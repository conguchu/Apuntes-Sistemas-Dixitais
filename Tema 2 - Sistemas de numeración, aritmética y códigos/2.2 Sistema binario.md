- Es un [[2 Sistema de numeración posicional]]

Solamente tiene **2 cifras**, el **1** y el **0**, es **base 2**.
*Por ejemplo*: `10.11 (base 2)` $= 1*2^1 + 0*2^0 + 1*2^{-1} + 1*2^{-2}$

- A cada cifra de un número en binario se la llama **bit**.

Con $n$ bits para **números enteros positivos** puedes representar el rango de **$[0,  2^n-1]$**.
*Por ejemplo:* Tenemos $n = 5$ bits, por lo que el número representable más grande es $11111$, que equivale a $31 = 2^5-1$
