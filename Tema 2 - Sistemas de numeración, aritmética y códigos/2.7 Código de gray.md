Es un código **sin pesos**, que puede ser de **cualquier número de bits**. 

Los **números consecutivos** en el código de gray tienen **1 bit de distancia** entre sí.

*Este es un ejemplo de códificación de grey para 4 bits, puede hacerse con los bits que se quiera*

### Conversión binario -> gray

Coincide el bit más significativo, luego se va sumando de izquierda a derecha cada par de bits adyacentes del código binario. Se desperdician los acarreos.

*Ejemplo para convertir el número `10110 (2)`*, la derecha es el nº en binario y la izquierda la salida de código grey, se lee de arriba a abajo ($10110_2 = 11101_{g}$):

![[{E929DF93-C7EC-438E-988F-8E0EFA09F839}.png]]

### Conversión gray -> binario

Se va sumando de izquierda a derecha el bit de código gray + el bit en binario también desperdiciando acarreos.

*Ejemplo para convertir el número `11011 (g)` a binario ($11011_{g} = 10010_{2}$):*
