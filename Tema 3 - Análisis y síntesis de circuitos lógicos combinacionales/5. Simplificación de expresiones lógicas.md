1. **Aplicar álgebra de Boole y leyes de De Morgan**: 
$$
\begin{aligned}
f(A,B,C) &= B\cdot(A \oplus C) + A\cdot B\cdot C \\
         &= B\cdot(\overline{A}\cdot C + A\cdot \overline{C}) + A\cdot B\cdot C \\
         &= B\cdot \overline{A}\cdot C + B\cdot A\cdot \overline{C} + A\cdot B\cdot C \\
         &= B\cdot \overline{A}\cdot C + B\cdot A\cdot \overline{C} + A\cdot B\cdot C + A\cdot B\cdot C \\
         &= A\cdot B\cdot (C + \overline{C}) + B\cdot C\cdot (A + \overline{A}) \\
         &= A\cdot B + B\cdot C \\
         &= B\cdot (A + C)
\end{aligned}
$$
